# Themeprovider Specification

> Generated by openlore v1.2.0 on 2026-10-11 20:36

## Purpose

Application-level provider that supplies the active UI theme (light/dark) to the component tree and
applies it to the document, acting as the single source of theme context for the app.

## Requirements

> `src/app/providers/ThemeProvider/index.ts`

### Requirement: ThemeProvider

The system SHALL wraps the application tree with theme context so all descendants can consume the current theme; re-exports the default provider implementation from './ui/themeprovider' as the module's public api.

#### Scenario: ProvidesThemeContextToChildren
<!-- openlore-test: priority=high (auto) -->
- **GIVEN** The application root is wrapped in ThemeProvider
- **WHEN** Any child component renders
- **THEN** The current theme is accessible via theme context to all descendants
- **AND** Rendered children appear unchanged inside the provider

#### Scenario: AppliesStoredThemeOnMount
- **GIVEN** A theme value persisted in the UI state (UISchema)
- **WHEN** ThemeProvider mounts
- **THEN** The stored theme is applied to the document root

#### Scenario: FallsBackToDefaultTheme
- **GIVEN** No theme has been stored or selected
- **WHEN** ThemeProvider mounts
- **THEN** The default (light) theme is applied

#### Scenario: ReRendersOnThemeChange
- **GIVEN** ThemeProvider is mounted with a child tree
- **WHEN** The active theme value changes
- **THEN** The document is updated to the new theme and children re-render with the new theme context

### Requirement: ApplyTheme

The system SHALL propagate the resolved theme onto the document (e.g., theme class or attribute on the root element) so global styles reflect the active theme.

#### Scenario: ThemeAppliedToDocument
- **GIVEN** ThemeProvider has resolved the active theme
- **WHEN** The theme is applied
- **THEN** The document root carries the theme class/attribute and global theme styles take effect

#### Scenario: ThemeSwitchUpdatesDocument
- **GIVEN** The app is rendered with the light theme
- **WHEN** Theme is switched to dark
- **THEN** The document root class/attribute changes and dark styles render without remounting children

## Technical Notes

- **Dependencies**: ui/ThemeProvider implementation (default export re-exported as public API), store (UI state / UISchema theme value)
