# Sidebar Specification

> Generated by openlore v1.2.0 on 2026-10-11 20:36

## Purpose

Application sidebar navigation widget: renders navigation links to app pages, language and theme
switchers, and supports collapsing/expanding with persisted UI state.

## Requirements

> `src/widgets/SideBar/index.ts`

### Requirement: RenderSidebar

The system SHALL the widget shall render the sidebar panel containing navigation links (e.g., main page, about page) and control widgets (language switcher, theme switcher), adapting layout/labels to the current collapsed state.

#### Scenario: ExpandedStateRendersFullSidebar
- **GIVEN** Sidebar is in expanded state and user is on the main page
- **WHEN** Sidebar is rendered
- **THEN** Navigation links with visible text labels are displayed
- **AND** Link to the main page is marked as active
- **AND** Language and theme switchers are rendered inside the sidebar

#### Scenario: CollapsedStateRendersCompactSidebar
- **GIVEN** Sidebar is in collapsed state
- **WHEN** Sidebar is rendered
- **THEN** Sidebar renders in compact width with the expand control available

### Requirement: ToggleCollapsed

The system SHALL the widget shall toggle the sidebar between collapsed and expanded states and persist the new state so it survives page reloads.

#### Scenario: CollapseExpandedSidebar
- **GIVEN** Sidebar is expanded
- **WHEN** The collapse toggle is triggered
- **THEN** Sidebar state becomes collapsed and the new state is persisted

#### Scenario: ExpandCollapsedSidebar
- **GIVEN** Sidebar is collapsed
- **WHEN** The expand toggle is triggered
- **THEN** Sidebar state becomes expanded and the new state is persisted
