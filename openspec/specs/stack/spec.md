# Stack Specification

> Generated by openlore v1.2.0 on 2026-10-11 20:36

## Purpose

Barrel module of the Stack UI kit in src/shared/ui/Stack; exposes the HStack and VStack layout
primitives as the module's public API.

## Requirements

> `src/shared/ui/Stack/index.ts`

### Requirement: ExportStackComponents

The system SHALL re-export hstack (from ./hstack/hstack) and vstack (from ./vstack/vstack) so consumers can import both layout primitives from '@/shared/ui/stack'.

#### Scenario: BarrelReExport
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** HStack exists in ./HStack/HStack and VStack exists in ./VStack/VStack
- **WHEN** A consumer imports from '@/shared/ui/Stack'
- **THEN** Both HStack and VStack resolve as valid components
- **AND** No circular or broken imports are introduced

> `src/shared/ui/Stack/index.ts`

### Requirement: HStack

The system SHALL renders children inside a horizontal (row-direction) flex container. must default cross-axis alignment to 'center' and forward standard flex props (gap, justify, wrap, grow, shrink, maxwidth) to the underlying flex component.

#### Scenario: HorizontalArrangement
- **GIVEN** Multiple child elements
- **WHEN** HStack renders
- **THEN** Children are laid out side by side with flexDirection 'row'

#### Scenario: DefaultAlignment
- **GIVEN** No align prop provided
- **WHEN** HStack renders
- **THEN** Cross-axis alignment defaults to 'center'
- **AND** alignItems style resolves to 'center'

#### Scenario: PropForwarding
- **GIVEN** gap='16' and justify='between'
- **WHEN** HStack renders
- **THEN** Gap and justify-content styles are applied to the row container
- **AND** The direction is fixed to 'row' and cannot be overridden by callers

> `src/shared/ui/Stack/index.ts`

### Requirement: VStack

The system SHALL renders children inside a vertical (column-direction) flex container. must default cross-axis alignment to 'start' and forward standard flex props (gap, justify, wrap, grow, shrink, maxwidth) to the underlying flex component.

#### Scenario: VerticalArrangement
- **GIVEN** Multiple child elements
- **WHEN** VStack renders
- **THEN** Children are stacked top-to-bottom with flexDirection 'column'

#### Scenario: DefaultAlignment
- **GIVEN** No align prop provided
- **WHEN** VStack renders
- **THEN** Cross-axis alignment defaults to 'start'
- **AND** alignItems style resolves to 'flex-start'

#### Scenario: PropForwarding
- **GIVEN** gap='8' and maxWidth={300}
- **WHEN** VStack renders
- **THEN** Gap and max-width styles are applied to the column container
- **AND** The direction is fixed to 'column' and cannot be overridden by callers

## Technical Notes

- **Dependencies**: HStack, VStack, Flex
