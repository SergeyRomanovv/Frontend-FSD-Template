# Loader Specification

> Generated by openlore v1.2.0 on 2026-10-11 20:36

## Purpose

Presents an animated ellipsis loading indicator (four CSS-animated dots) to signal that asynchronous
content is being loaded. Marked as deprecated in favor of the redesigned UI components.

## Requirements

> `src/shared/ui/Loader/index.ts`

### Requirement: Render

The system SHALL renders the loading indicator: a container div carrying the base 'lds-ellipsis' class with four child divs that are animated via the imported scss keyframes.

#### Scenario: DefaultRender
- **GIVEN** Loader is rendered without a className prop
- **WHEN** Loader is invoked
- **THEN** A container div with the 'lds-ellipsis' base class is rendered containing exactly four child divs

#### Scenario: CustomClassNameApplied
- **GIVEN** A custom className prop is provided
- **WHEN** Loader is invoked
- **THEN** The resulting container includes both the base 'lds-ellipsis' class and the provided custom class
- **AND** The base class 'lds-ellipsis' is never removed by the custom className

#### Scenario: AnimationVisibleWhileLoading
- **GIVEN** The Loader.scss styles are loaded
- **WHEN** The component is mounted in the DOM
- **THEN** The four dots animate via the lds-ellipsis1/2/3 keyframes to visually indicate ongoing loading

#### Scenario: ThemeAwareDotColor
- **GIVEN** A theme defining --inverted-bg-color is active
- **WHEN** Loader is rendered
- **THEN** Dots use the theme's inverted background color so the loader adapts to light/dark themes

### Requirement: DeprecationMarker

The system SHALL documents that the component is deprecated; consumers should migrate to the new components from the redesigned folder.

#### Scenario: DeprecationIsSignaledToConsumers
<!-- openlore-test: priority=low (auto) -->
- **GIVEN** The Loader module is inspected or imported in an IDE
- **WHEN** The exported Loader symbol is referenced
- **THEN** Tooling surfaces the @deprecated warning directing consumers to the redesigned components folder
