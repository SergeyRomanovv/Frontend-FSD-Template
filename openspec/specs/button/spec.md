# Button Specification

> Generated by openlore v1.2.0 on 2026-10-11 20:36

## Purpose

Reusable shared UI button component that renders a native HTML button with configurable visual
variant (clear/outline/filled), design-system size (m/l/xl), semantic color (normal/success/error),
square/fullWidth layout flags, disabled state, and left/right addon slots; forwards refs and passes
through all native button attributes.
